## Directory Purposes

**`.planning/`:**
- Purpose: Holds GSD planning and codebase analysis artifacts for this repository.
- Contains: `.planning/codebase/ARCHITECTURE.md`, `.planning/codebase/STRUCTURE.md`.
- Key files: `.planning/codebase/ARCHITECTURE.md`, `.planning/codebase/STRUCTURE.md`.

**`dist/`:**
- Purpose: Contains generated runtime assets loaded by SillyTavern.
- Contains: `dist/index.js` generated by webpack, `dist/style.css` generated by Sass.
- Key files: `dist/index.js`, `dist/style.css`.

**`images/`:**
- Purpose: Stores README visuals for overview, per-chat schema editing, and settings behavior.
- Contains: `images/overview.png`, `images/modify_for_this_chat.png`, `images/settings.gif`.
- Key files: `images/overview.png`, `images/modify_for_this_chat.png`, `images/settings.gif`.

**`src/`:**
- Purpose: Stores all authored extension source code except runtime HTML templates.
- Contains: Main entry, config/defaults, parser utilities, schema example generation, React component directories, hook directories, and Sass.
- Key files: `src/index.tsx`, `src/config.ts`, `src/parser.ts`, `src/schema-to-example.ts`.

**`src/components/`:**
- Purpose: Stores React UI components for extension settings.
- Contains: `src/components/Settings.tsx`, including the settings manager singleton and `WTrackerSettings` component.
- Key files: `src/components/Settings.tsx`.

**`src/hooks/`:**
- Purpose: Stores small React hooks shared by component code.
- Contains: `src/hooks/useForceUpdate.ts`.
- Key files: `src/hooks/useForceUpdate.ts`.

**`src/styles/`:**
- Purpose: Stores Sass source compiled into extension CSS.
- Contains: `src/styles/main.scss`.
- Key files: `src/styles/main.scss`.

**`templates/`:**
- Purpose: Stores HTML fragments rendered by SillyTavern template APIs.
- Contains: Extension menu button markup and chat schema selection popup markup.
- Key files: `templates/buttons.html`, `templates/modify_schema_popup.html`.

**`node_modules/`:**
- Purpose: Stores installed npm dependencies used by build/test/dev workflows.
- Contains: Dependency packages installed from `package-lock.json`.
- Key files: Not applicable; do not edit files under `node_modules/`.

## Key File Locations

**Entry Points:**
- `manifest.json`: SillyTavern load contract for `dist/index.js`, `dist/style.css`, load order, and `wtrackerGenerateInterceptor`.
- `src/index.tsx`: Source entry used by webpack and runtime side-effect entry after bundle load.
- `src/index.tsx:949`: Settings initialization side effect that starts the extension by calling `main()`.
- `src/index.tsx:943`: `main()` calls `renderReactSettings()` and `initializeGlobalUI()`.
- `webpack.config.cjs:6`: Webpack entry points at `src/index.tsx`.
- `package.json:8`: `npm run dev` Sass/webpack watch workflow.
- `package.json:9`: `npm run build` production Sass/webpack workflow.

**Configuration:**
- `package.json`: npm scripts, dependencies, peer dependencies, and package metadata.
- `package-lock.json`: Exact npm dependency versions.
- `tsconfig.json`: TypeScript `NodeNext`, strict mode, JSX runtime, `rootDir` `src`, and `outDir` `dist`.
- `webpack.config.cjs`: ESM output bundle, TypeScript/React loaders, extension aliasing, source maps, and production minification.
- `babel.config.json`: Babel presets for env and TypeScript.
- `jest.config.mjs`: Jest `ts-jest` ESM configuration.
- `.prettierrc.json`: Prettier formatting rules for TypeScript/TSX and HTML.
- `.gitignore`: Ignores `node_modules/`, source maps, local IDE state, `.env`, generated helper outputs, and temporary script outputs.

**Core Logic:**
- `src/index.tsx`: Runtime coordinator, tracker rendering, tracker storage, generation, event handlers, DOM integration, chat metadata updates.
- `src/config.ts`: Shared settings interfaces, constants, default prompt templates, default JSON schema, default tracker HTML, and `EXTENSION_KEY`.
- `src/parser.ts`: Parse and normalize model JSON/XML responses.
- `src/schema-to-example.ts`: Generate prompt example responses from JSON schema.
- `src/components/Settings.tsx`: Settings UI and settings persistence surface.

**Runtime HTML/CSS:**
- `templates/buttons.html`: Extension menu item for modifying chat schema preset.
- `templates/modify_schema_popup.html`: Popup select for active chat schema preset.
- `src/styles/main.scss`: Authored Sass for settings layout, tracker controls, group toggles, and tracker tables.
- `dist/style.css`: Generated CSS loaded by `manifest.json`.

**Testing:**
- `jest.config.mjs`: Test runner configuration exists.
- `src/**/*.test.ts`: Use this naming/location for new tests; no test files are present in the repo.
- `src/**/*.spec.ts`: Also compatible with Jest defaults; no spec files are present in the repo.

## Naming Conventions

**Files:**
- Use `PascalCase.tsx` for React components, as in `src/components/Settings.tsx`.
- Use `useCamelCase.ts` for React hooks, as in `src/hooks/useForceUpdate.ts`.
- Use lower-case or kebab-case utility modules, as in `src/parser.ts` and `src/schema-to-example.ts`.
- Use lower-case config/build filenames at repo root, as in `webpack.config.cjs`, `jest.config.mjs`, and `babel.config.json`.
- Use snake_case template names for multi-word SillyTavern HTML templates, as in `templates/modify_schema_popup.html`; short templates may use simple lower-case names such as `templates/buttons.html`.

**Directories:**
- Use short lower-case directory names for source groupings: `src/components/`, `src/hooks/`, `src/styles/`, `templates/`, `images/`, `dist/`.
- Put React code under `src/components/` and shared React hooks under `src/hooks/`.
- Put generated runtime assets under `dist/`; put authored source under `src/`.

**Runtime Identifiers:**
- Use `WTracker` as the persisted extension key from `src/config.ts:409`.
- Use `wtracker*` or `WTracker*` prefixes for extension-specific globals and functions, as in `wtrackerGenerateInterceptor` in `manifest.json:11`.
- Use `.wtracker-*`, `.mes_wtracker`, or `.ignore_wtracker_toggle` for extension CSS/DOM selectors, as in `src/styles/main.scss` and `src/index.tsx`.

## Where to Add New Code

**New Tracker Runtime Feature:**
- Primary code: Add focused helpers under `src/` and import them from `src/index.tsx`; use paths such as `src/tracker-storage.ts`, `src/generation.ts`, or `src/ui.ts` for substantial extracted behavior.
- Tests: Add `src/tracker-storage.test.ts`, `src/generation.test.ts`, or matching `*.test.ts` files next to focused modules.
- Integration point: Wire the feature from `initializeGlobalUI()` or `generateTracker()` in `src/index.tsx` only after helper behavior is isolated.

**New Settings Control:**
- Primary code: Add settings fields and defaults in `src/config.ts`.
- UI code: Add controls to `src/components/Settings.tsx` using the existing `updateAndRefresh()` persistence pattern.
- Styles: Add setting-specific styles to `src/styles/main.scss` under `.wtracker-settings`.
- Tests: Add pure settings/default tests near `src/config.test.ts` or component-adjacent tests when a React test setup is introduced.

**New Parser Or Prompt Mode:**
- Primary code: Add parsing behavior to `src/parser.ts` and prompt-example behavior to `src/schema-to-example.ts`.
- Config code: Add prompt mode enum/defaults in `src/config.ts`.
- Runtime integration: Branch from `generateTracker()` in `src/index.tsx`.
- Tests: Add `src/parser.test.ts` and `src/schema-to-example.test.ts` for pure logic coverage.

**New SillyTavern Popup Or Menu Item:**
- Template: Add HTML fragment under `templates/`.
- Runtime loader: Call `globalContext.renderExtensionTemplateAsync()` from `src/index.tsx`.
- Styles: Add related selectors to `src/styles/main.scss`.

**New React Component/Module:**
- Implementation: Add component files under `src/components/`.
- Hooks: Add reusable hooks under `src/hooks/`.
- Shared types/defaults: Add extension settings types and defaults to `src/config.ts` when persisted.

**Utilities:**
- Shared pure helpers: Add top-level modules under `src/`, following `src/parser.ts` and `src/schema-to-example.ts`.
- Avoid adding unrelated pure helpers to `src/index.tsx`; keep `src/index.tsx` focused on extension bootstrap and integration wiring.

**Generated Assets:**
- Build output: Regenerate `dist/index.js` and `dist/style.css` with `npm run build` from `package.json`.
- Do not manually edit `dist/index.js` or `dist/style.css`; edit `src/index.tsx`, `src/styles/main.scss`, or source modules instead.
